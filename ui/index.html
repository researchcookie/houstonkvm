Display

Paste text

Typed as on a US keyboard: plain ASCII letters, digits and symbols, newlines and tabs. Click where it should go on the machine's screen first.

Input health

Sends 20 status checks to the adapter and reads its settings. Nothing is typed or clicked on the target, and nobody can take control during the few seconds it runs.

Each key press and mouse move crosses the serial link 12 times faster. This rewrites the adapter's stored speed and may reset it, so keys and buttons are released and nobody can take control for the few seconds it takes. If the adapter can't switch, it's left as it was.

Settings

Stored for a future per-viewer bitrate feature — the server currently encodes one shared stream per target at a fixed bitrate, so this isn't applied yet.

Automated clients authenticate with an API token instead of a browser session — send Authorization: Bearer <token>. Use GET /api/targets to discover targets and /api/targets/<id>/… to act on one. Give each client only what it needs: a token that only looks can't drive a target or change anything, and every token should expire unless you have a reason.

      How to trust HoustonKVM's CA

      Do this before turning HTTPS on: a browser that doesn't trust the CA shows a warning instead of the page.

      • Mac (Safari, Chrome): open the downloaded file, add it to the System keychain, then open it in Keychain Access and set Trust → When using this certificate to Always Trust. Quit and reopen the browser.
      • Windows (Edge, Chrome): open the file, Install Certificate, Local Machine, then Trusted Root Certification Authorities.
      • Firefox: Settings → Privacy & Security → View Certificates → Authorities → Import, and tick trust this CA to identify websites.
      • Linux: copy it to /etc/pki/ca-trust/source/anchors/ and run update-ca-trust (or /usr/local/share/ca-certificates/ and update-ca-certificates).
      • Many computers: push it as a trusted root by Group Policy, Ansible or your MDM.

      Advanced

      Video connections: STUN and TURN

      Not needed on a LAN or over a VPN, and then nothing contacts a server outside your network. Add one only if viewers reach this server through NAT.

      More about STUN and TURN

      Low-latency video uses them, both on this server and in every viewer's browser. Without any, browsers connect to this server's own addresses. If a server listed here doesn't answer, low-latency video goes ahead without it after a couple of seconds, which works on a LAN; the server's log says when that happens.

      Set in the server's configuration (--ice-server in /etc/houstonkvm/houstonkvm.conf), so they can't be changed here.
